# Portfólio — Leonardo Graça Aguiar

Portfólio pessoal desenvolvido para centralizar meus principais projetos de desenvolvimento web, reunindo aplicações autorais e sites reais criados para empresas que seguem ativos em produção.

**Acesse no ar:** [portifolioyap.vercel.app](https://portifolioyap.vercel.app)

## Sobre o projeto
A página foi estruturada para servir como vitrine técnica direta ao ponto, facilitando o acesso aos meus projetos publicados, códigos-fonte e canais profissionais em uma interface responsiva para desktop e mobile.

## Stack utilizada
- TypeScript
- Vercel (deploy e hospedagem)
